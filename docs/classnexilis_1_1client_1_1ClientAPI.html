◆ getActiveRooms()

std::vector< client::Room > nexilis::client::ClientAPI::getActiveRooms ( ) const
inline

Return a snapshot copy of the currently active rooms (thread-safe). The copy is taken under the room mutex so that reads never race with the network thread's room updates. Mutating the returned copy has no effect on the API's internal state.
