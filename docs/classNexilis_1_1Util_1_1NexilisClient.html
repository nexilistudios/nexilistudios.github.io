Detailed Description

High level, engine-agnostic client for the Nexilis bindings. Wraps the full connection lifecycle (config, BoostTCP / BoostUDP clients, room join) and exposes the connected room as plain data through callbacks, so it can be driven from any game loop.

Wire the callbacks from your engine layer with anonymous functions, e.g. in Unity:

client = new NexilisClient
{
ServerAddress = "127.0.0.1",
LogHandler = (level, msg) => Debug.Log($"[Nexilis] {msg}"),
};
client.OnReady += () => Debug.Log("Connected!");
client.OnRemoteClientPosition += (id, pos) => remoteGo.transform.position = new Vector3(pos.X, pos.Y, pos.Z);
await client.ConnectAsync();
