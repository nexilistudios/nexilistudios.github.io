std::string nexilis::crypto::deriveKey ( const std::string & password,
const std::string & salt,
std::size_t length = kKeyLength,
int iterations = 100000 )

Derive a key from a password via PBKDF2-HMAC-SHA256.

The result is cached per (password, salt) pair. This is the primitive behind deriveMessageKey(); it is public so the TLS layer can derive its pre-shared key from the same password with its own domain-separated salt.

Parameters
passwordThe connection password stored in the AuthConfig.
saltA domain-separating salt string appended to the "nexilis-" domain prefix by the callers.
lengthKey length in bytes (defaults to the AES-GCM key length).
iterationsPBKDF2 iteration count (defaults to the message-key count).
Returns
The derived key, or an empty string on failure.
