◆ ClientCreationHandler

using nexilis::server::RoomStorage::ClientCreationHandler = std::function<bool(const User&, const RoomData&)>

Authorizes a client room creation request. Unset denies all client creation, so the application must opt in before serving such requests. Install this and Room::setAdmissionHandler before serving room traffic.
