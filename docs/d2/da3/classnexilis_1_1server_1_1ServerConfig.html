bool nexilis::server::ServerConfig::isTlsEnabled ( ) const
inline

Whether TCP connections are encrypted with TLS-PSK.

Note
The pre-shared key is derived from the passphrase, so a client only connects when it knows the same passphrase. On by default for Boost TCP; a passphrase is required unless disabled.
