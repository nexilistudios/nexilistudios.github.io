◆ GetRoom()

Room Nexilis.Client.RoomsCollection.GetRoom ( ulong index)
inline

Gets a non-owning wrapper for the room at index .

The native side hands out a pointer to a shared, reused wrapper, so the returned room is only valid until the next index is requested and must not be disposed. Use GetRoomInfos when you need values that stay valid after the collection is gone.

Exceptions
ArgumentOutOfRangeExceptionThrown when index is out of range.
ObjectDisposedExceptionThrown when the collection has been disposed.
