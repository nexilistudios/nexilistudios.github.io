void nexilis::server::SignalHandler::install ( )
static

Install signal handlers for SIGINT and SIGTERM. On Windows, installs a console control handler for Ctrl+C, Ctrl+Break, console close, logoff, and system shutdown events. This function is idempotent; calling it multiple times has no additional effect.

void nexilis::server::SignalHandler::setShutdownCallback ( std::function< void()>  callback)
static

Set a callback to be invoked once by waitForShutdown() for each shutdown request. The callback runs on the waiting thread, outside the OS signal/control handler. Call waitForShutdown() to dispatch the callback.

Parameters
callbackFunction to call on shutdown signal. Pass nullptr to remove.
