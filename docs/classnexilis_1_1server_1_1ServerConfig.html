bool nexilis::server::ServerConfig::isTlsEnabled ( ) const
inline

Whether TCP connections are encrypted with TLS-PSK.

Note
The pre-shared key is derived from the passphrase, so a client only connects when it knows the same passphrase. Off by default so plaintext traffic stays plaintext unless explicitly enabled.
