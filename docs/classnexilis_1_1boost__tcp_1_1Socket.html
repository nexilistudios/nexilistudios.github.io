Detailed Description

Thin wrapper around a boost::asio TCP connection.

When a TLS context is supplied via enableTls() the transport is upgraded to TLS-PSK, typically derived from the Nexilis authentication passphrase. Without it the connection stays plaintext. TLS and plaintext are mutually exclusive per connection: the TLS handshake happens lazily on the first I/O operation and a mismatch simply fails the connection instead of silently downgrading.
