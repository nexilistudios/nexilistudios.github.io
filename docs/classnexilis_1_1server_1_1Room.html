◆ damagePlayer()

bool nexilis::server::Room::damagePlayer ( uint64_t clientId,
float damage )

Apply damage to a player. The player's health is clamped to 0.

Returns
True if this call brought the player down to 0 health (i.e. the player was alive before this hit). Damaging an already-dead player is a no-op that returns false, so a single kill/death is never recorded twice.
