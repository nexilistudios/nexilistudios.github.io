◆ isTlsEnabled()

bool nexilis::client::ClientConfig::isTlsEnabled ( ) const
inline

Whether the TCP connection to the server is encrypted with TLS-PSK.

Note
The pre-shared key is derived from the password, so the client can only connect to a server that knows the same password. Off by default so plaintext traffic stays plaintext unless enabled.
